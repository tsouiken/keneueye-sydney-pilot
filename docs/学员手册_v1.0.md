# 第一天：眉眼基础结构

## 1.1 为什么是眉毛？

人类在 **50 毫秒** 内 — 眨一下眼睛的时间 — 就会对一张脸做出判断。

这个判断不是理性的。你的大脑在你自己还没意识到的时候，就已经在回答三个问题：
- 这个人值得信任吗？
- 这个人好相处吗？
- 这个人说话算数吗？

而决定这三个答案的关键因素之一，是 **眉毛**。

不是眼睛，不是鼻子，是眉毛。因为：
- 眉毛是脸部最突出的 **结构特征**
- 眉毛决定了你的 **表情基调**
- 眉毛是脸部 **第一个被注意到的区域**

### 核心原则

> **眉毛不是装饰，是信号。**

你的眉毛在持续发送信号 — 即使你什么都没说。问题是：它发送的信号，是不是你想发送的那个？

---

## 1.2 眉毛三要素

任何眉毛都可以拆成三个部分：

```
       眉峰
    ┌────┼────┐
   ／     │     ＼
 ／       │       ＼
├─────────┼─────────┤
眉头      │        眉尾
          │
       眉眼距
```

### 眉头（起点）

| 位置 | 给人的感觉 |
|------|-----------|
| 与鼻翼对齐 | 标准，平衡 |
| 往内靠（过近） | 严肃、有压迫感 |
| 往外散（过远） | 温和、但可能显得松散 |

### 眉峰（最高点）

| 位置 | 给人的感觉 |
|------|-----------|
| 在黑眼珠外缘上方 | 标准，自然 |
| 偏外侧（靠近眉尾） | 柔和、温和 |
| 偏内侧（靠近眉头） | 强势、有决断力 |

### 眉尾（终点）

| 位置 | 给人的感觉 |
|------|-----------|
| 与鼻翼-眼尾连线对齐 | 标准，平衡 |
| 高于眉头 | 有精神、有气势 |
| 低于眉头 | 温和、但可能显得疲惫 |

### 眉眼距

| 距离 | 给人的感觉 |
|------|-----------|
| 适中（约一根手指宽） | 标准，平衡 |
| 过近 | 精明、锐利、有压迫感 |
| 过远 | 温和、开放、但可能显得松散 |

---

## 1.3 三种基础眉型

### 平眉

```
─────────────────────
```

**特征：** 整条眉毛接近水平，眉峰不明显。

| 面向 | 信号 |
|------|------|
| 给人的感觉 | 稳定、温和、好相处 |
| 优势 | 亲和力高，没有威胁感 |
| 风险 | 容易显得没有个性、缺乏决断力 |
| 适合场景 | 服务业、需要亲和力的工作 |
| 不适合场景 | 需要权威感、需要拍板决定的位置 |

### 剑眉（上扬眉）

```
                    ╲
                   ╲
                  ╲
```

**特征：** 眉头粗、眉尾细，整条眉毛往上走，眉峰明显。

| 面向 | 信号 |
|------|------|
| 给人的感觉 | 有权威感、有决断力、有气势 |
| 优势 | 建立专业形象，说话有分量 |
| 风险 | 容易让人感到压力、不好亲近 |
| 适合场景 | 管理职、需要建立权威的人 |
| 不适合场景 | 需要大量沟通协调的角色 |

### 下垂眉

```
                 ╱
               ╱
             ╱
```

**特征：** 眉尾低于眉头，呈现「八」字型。

| 面向 | 信号 |
|------|------|
| 给人的感觉 | 温和、好说话、没有威胁性 |
| 优势 | 让人放下戒心 |
| 风险 | 容易看起来没精神、缺乏决断力 |
| 适合场景 | 需要让人放松的场合 |
| 不适合场景 | 需要展现领导力的时候 |

## 1.4 练习：眉型辨识

**练习 1：看照片，指出眉型**

准备三张照片（平眉、剑眉、下垂眉各一）。
对每张照片回答：
1. 这是什么眉型？
2. 眉头位置在哪里？
3. 眉峰位置在哪里？
4. 眉尾位置在哪里？

**练习 2：看照片，说信号**

对同一张照片回答：
1. 这个眉型在发送什么信号？
2. 这个信号跟照片中的人的职业匹配吗？
3. 如果不匹配，落差在哪里？

# 第二天：信号判读系统

## 2.1 信号 vs 性格

**最重要的原则：**

> **眉毛发送的是「信号」，不是「性格」。**

意思是：
- 上扬眉 ≠ 这个人强势
- 下垂眉 ≠ 这个人软弱
- 平眉 ≠ 这个人没个性

正确的说法是：
- 上扬眉 **发送** 强势的信号
- 下垂眉 **发送** 温和的信号
- 平眉 **发送** 稳定的信号

**为什么这个区分很重要？**

因为一个人可以同时是「内心柔软但眉毛上扬」的人。如果直接说「你看起来很强势」，对方会觉得被误解。但如果改成「你的眉毛发送的是强势的信号，这跟你实际想表达的可能有落差」— 对方会愿意听下去。

---

## 2.2 信号判读框架

### 三个维度

```
权威感 ────────────── 亲和力
         ↑
       平衡点

锐利度 ────────────── 柔和度
         ↑
       平衡点

存在感 ────────────── 融入感
         ↑
       平衡点
```

### 每个维度的眉型对应

**权威感 vs 亲和力**

| 偏向 | 眉型特征 | 发送的信号 |
|------|---------|-----------|
| 权威感强 | 眉峰明显、位置偏内、线条锐利 | 「我有决定权」 |
| 亲和力强 | 眉峰柔和、位置偏外、线条圆润 | 「我们可以商量」 |
| 平衡 | 眉峰适中、线条自然 | 「我专业且好沟通」 |

**锐利度 vs 柔和度**

| 偏向 | 眉型特征 | 发送的信号 |
|------|---------|-----------|
| 锐利 | 线条清晰、角度明显、颜色深 | 「我很清楚我要什么」 |
| 柔和 | 线条模糊、角度圆润、颜色浅 | 「我们可以慢慢来」 |
| 平衡 | 线条自然、角度适中 | 「我有想法也愿意听」 |

**存在感 vs 融入感**

| 偏向 | 眉型特征 | 发送的信号 |
|------|---------|-----------|
| 存在感强 | 眉毛浓、粗、明显 | 「注意我」 |
| 融入感强 | 眉毛淡、细、不显眼 | 「我不想被注意」 |
| 平衡 | 眉毛浓度适中、结构清楚 | 「我在这里，但不需要 spotlight」 |

---

## 2.3 落差分析

落差 = 一个人想发送的信号 vs 实际发送的信号

### 三种常见落差

**落差一：太凶**

| 项目 | 内容 |
|------|------|
| 本人想发送 | 专业、有能力 |
| 实际发送 | 严肃、不好亲近 |
| 眉型特征 | 眉峰太明显、眉头太近、线条太锐利 |
| 校准方向 | 柔化眉峰、拉开眉头间距 |

**落差二：太软**

| 项目 | 内容 |
|------|------|
| 本人想发送 | 温和、好相处 |
| 实际发送 | 没精神、没主见 |
| 眉型特征 | 眉尾下垂、眉毛太淡、眉峰不明显 |
| 校准方向 | 提升眉尾、增加眉毛浓度、建立眉峰 |

**落差三：太模糊**

| 项目 | 内容 |
|------|------|
| 本人想发送 | 不确定（「就…正常就好」） |
| 实际发送 | 没有记忆点、容易被忽略 |
| 眉型特征 | 眉型不明确、杂毛多、结构松散 |
| 校准方向 | 建立明确的眉型结构、清理杂毛 |

---

## 2.4 练习：落差判读

**练习 3：三张照片，找出落差**

对每张照片：
1. 这个人的职业是什么？（假设）
2. 他/她想发送什么信号？
3. 实际发送了什么信号？
4. 落差在哪里？
5. 校准方向是什么？

**练习 4：角色扮演**

两人一组：
- A 描述自己的职业和想发送的信号
- B 观察 A 的眉毛，说出实际发送的信号
- A 反馈：B 说的准不准？
- 两人一起讨论校准方向

# 第三天：案例实战与校准

## 3.1 校准原则

### 三条铁律

1. **不改变本质，只调整信号**
   - 不是把一个人变成另一个人
   - 是让眉毛发送的信号，跟上这个人已经有的能力

2. **最小干预**
   - 先调一个地方（通常是眉峰或眉尾）
   - 观察效果，再决定下一步
   - 不要一次改太多

3. **可逆优先**
   - 先做可逆的调整（修眉、画眉）
   - 再做不可逆的调整（雾眉、飘眉）
   - 给客户适应的时间

### 校准顺序

```
第一步：清理杂毛
   ↓
第二步：建立眉峰位置
   ↓
第三步：调整眉尾方向
   ↓
第四步：调整眉头间距
   ↓
第五步：调整眉眼距
   ↓
第六步：浓度与颜色
```

---

## 3.2 五种常见校准方向

### 方向一：太散 → 建立结构

| 项目 | 内容 |
|------|------|
| 特征 | 眉型模糊、杂毛多、没有明确的眉峰 |
| 发送的信号 | 「我还在犹豫」 |
| 校准 | 清理杂毛 → 建立眉峰 → 收干净眉尾 |
| 效果 | 从「还在想」变成「想好了」 |

### 方向二：太凶 → 柔化

| 项目 | 内容 |
|------|------|
| 特征 | 眉峰太明显、眉头太近、线条锐利 |
| 发送的信号 | 「别靠近我」 |
| 校准 | 拉开眉头 → 柔化眉峰 → 稍微提升眉尾 |
| 效果 | 从「别靠近」变成「可以聊聊」 |

### 方向三：太软 → 建立力道

| 项目 | 内容 |
|------|------|
| 特征 | 眉尾下垂、眉毛太淡、眉峰不明显 |
| 发送的信号 | 「我没意见」 |
| 校准 | 提升眉尾 → 建立眉峰 → 增加浓度 |
| 效果 | 从「我没意见」变成「我有想法」 |

### 方向四：太淡 → 增加存在感

| 项目 | 内容 |
|------|------|
| 特征 | 眉毛稀疏、颜色淡、几乎看不见 |
| 发送的信号 | 「别注意我」 |
| 校准 | 增加浓度 → 建立结构 → 眉色调整 |
| 效果 | 从「隐形」变成「被看见」 |

### 方向五：不对称 → 平衡

| 项目 | 内容 |
|------|------|
| 特征 | 左右眉型不一致、高低不同 |
| 发送的信号 | 「不稳定」 |
| 校准 | 以优势侧为基准，调整弱势侧 |
| 效果 | 从「不稳定」变成「可靠」 |

## 3.3 完整案例流程

### 案例流程（约 20 分钟）

```
① 客户主诉（2 分钟）
   「你希望别人怎么看你？」

② 观察（3 分钟）
   眉型 → 三要素 → 信号

③ 反馈（5 分钟）
   「你的眉毛目前发送的是____信号」
   「这跟你想要的____有____落差」
   「校准方向是____」

④ 校准建议（5 分钟）
   具体要调哪里、怎么调

⑤ 确认（5 分钟）
   客户理解了吗？
   客户愿意尝试吗？
   下一步是什么？
```

## 3.5 课后作业

### 作业一：观察 3 个人

本周内，观察 3 个人的眉毛（朋友、同事、路人皆可）。
对每个人：
1. 这是什么眉型？
2. 发送了什么信号？
3. 如果校准，你会调哪里？

### 作业二：提交一个案例

选一个人（自己或朋友），拍一张正面自然光照，提交给 Ken 复核。
提交时附上：
1. 这个人的职业
2. 想发送的信号
3. 你的判读
4. 你的校准建议

Ken 会在 48 小时内回覆复核意见。

## 附录

### A. 常见问题

**Q：校准眉毛是不是在教人「伪装」？**
A：不是。校准是让眉毛发送的信号跟上你已经有的能力。如果你有专业能力但眉毛让你看起来没精神，那不是伪装，是移除干扰。

**Q：一次校准能维持多久？**
A：修眉约 2-4 周，画眉每天，雾眉/飘眉 1-3 年。课程教的是判断框架，不是特定技术。

**Q：需要美术基础吗？**
A：不需要。课程教的是观察和判断，不是画眉技术。

**Q：学完可以帮别人看吗？**
A：可以。但本课程不提供「讲师认证」或「品牌授权」。你可以用这套框架帮朋友看，但不能以 KenEyeCue 名义对外收费服务。

### B. 推荐工具

| 工具 | 用途 |
|------|------|
| 修眉刀 | 清理杂毛 |
| 眉笔（灰棕色） | 测试眉型 |
| 眉刷 | 整理毛流 |
| 正面自然光照 | 观察用 |

### C. 术语对照

| 术语 | 说明 |
|------|------|
| 信号 | 眉毛发送给别人的第一印象讯息 |
| 落差 | 想发送的信号 vs 实际发送的信号 |
| 校准 | 调整眉毛使信号更接近目标 |
| 三要素 | 眉头、眉峰、眉尾 |
| 眉眼距 | 眉毛下缘到眼睛上缘的距离 |
