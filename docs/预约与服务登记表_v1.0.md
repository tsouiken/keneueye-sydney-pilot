## 五、预约流程

```
① 学员填写登记表 → 传给 Bonnie
② Bonnie 确认时段 → 回复学员
③ 学员完成付款 → 预约成立
④ 课前 72 小时 → 提醒通知
⑤ 课前 24 小时 → 最终确认
```

### 取消规则

| 取消时间 | 退款比例 |
|---------|:-------:|
| 开课前 14 天以上 | 全额退费 |
| 开课前 7-13 天 | 退 50% |
| 开课前 7 天内 | 不退费 |
| 开课后 | 不退费，可协调转梯次 |

### 满意保证

第一堂课结束后，若学员认为课程不符合预期：
- 基础方案学员：全额退费
- 完整方案学员：可降转至基础方案，退差额
- 申请期限：第一堂课结束后 24 小时内向 Bonnie 提出
