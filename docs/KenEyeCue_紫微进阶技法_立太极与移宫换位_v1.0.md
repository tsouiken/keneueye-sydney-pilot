> 存檔日期：2026-08-13

## 一、技法概述

### 什麼是立太極／移宮換位？

紫微斗數以「命宮」為太極點（中心），十二宮由此展開。立太極是當要深入分析某個特定領域時，以該領域的宮位為新的太極點（新命宮），重新推導十二宮，從新的角度解讀。

移宮換位（轉宮）是立太極的具體操作：把原命盤的某宮位「移」到新命宮的位置，十二宮隨之重新排列。

### 為什麼要用在眉型設計？

原 5 維度（命宮/福德/事業/財帛/遷移）是「整體」分析。當客戶特別在意某個領域（如財運、事業、感情）時，立太極於該宮，可以看見「這個領域的眉型需求」——更精準、更投其所好。

## 三、基本操作（如何立太極）

### 操作步驟

1. 確認原命盤十二宮（已排盤）
2. 選定要深化的領域宮位（如財帛宮）
3. 以該宮位為「新命宮」（立太極）
4. 新十二宮依序重新排列（新命宮 → 新兄弟 → 新夫妻…）
5. 解讀新命宮及相關宮位的星曜

### 轉宮偏移規則（固定）

| 新宮位 | 偏移 | 新宮位 | 偏移 |
|--------|:----:|--------|:----:|
| 命宮 | 0 | 僕役 | 7 |
| 兄弟 | 1 | 官祿（事業） | 8 |
| 夫妻 | 2 | 田宅 | 9 |
| 子女 | 3 | 福德 | 10 |
| 財帛 | 4 | 父母 | 11 |
| 疾厄 | 5 | | |
| 遷移 | 6 | | |

註：偏移以地支順序計算（子→丑→寅…），超過亥則循環回子。
例：立太極於財帛宮（卯），新事業 = 卯 + 8 = 亥。

## 四、眉型設計應用（轉宮深化 5 維度）

### 應用原則

```
原 5 維度：整體眉型基調（先看）
    ↓
立太極：深化客戶最在意的領域（再看）
    ↓
整合：原基調 + 領域深化 = 最終眉型
```

### 立太極於各宮的眉型應用（v1 草案，待 Ken 校準）

| 立太極於 | 眉型焦點 | 依據 |
|----------|----------|------|
| 命宮 | 整體眉型基調 | 原 5 維度 |
| 福德 | 眉型軟硬度（內在） | 外剛內柔 |
| 事業 | 眉峰（行動力） | 開創 |
| 財帛 | 眉尾（開創／守成） | 開創財 |
| 遷移 | 眉型輪廓（外在形象） | 舞台 |

### 實例：鄒毅宏（命宮亥）

**原命盤 5 維度**

| 維度 | 宮位 | 星曜 | 解讀 |
|------|------|------|------|
| 命宮 | 亥 | 武曲＋巨門 | 開創＋表達 |
| 福德 | 酉 | 廉貞＋太陰 | 外剛內柔 |
| 事業 | 未 | 空（借夫妻宮天機天梁） | 智慧沉穩 |
| 財帛 | 卯 | 破軍（身宮） | 開創財 |
| 遷移 | 巳 | 空（借命宮武曲巨門） | 實力＋口才 |

**立太極於財帛宮（卯）深化財運眉型**

| 新宮位 | 位置 | 星曜 | 解讀 |
|--------|------|------|------|
| 新命宮 | 卯 | 破軍 | 財運眉型基調「開創」 |
| 新福德 | 丑 | 天機＋天梁 | 財運的內在：智慧沉穩 |
| 新事業 | 亥 | 武曲＋巨門 | 財運的戰場：行動＋口才 |
| 新財帛 | 未 | 空，借對宮 | 財中財：需借力 |
| 新遷移 | 酉 | 廉貞＋太陰 | 財運的舞台：內外兼修 |

→ 財運眉型結論：眉尾上揚（開創）＋ 聚攏（守成）＋ 眉峰明確（行動力）——與原設計一致，但更聚焦眉尾

**立太極於事業宮（未）深化事業眉型**

| 新宮位 | 位置 | 星曜 | 解讀 |
|--------|------|------|------|
| 新命宮 | 未 | 空，借夫妻宮天機＋天梁 | 事業靠智慧與人脈 |
| 新事業 | 卯 | 破軍 | 事業的戰場：開創 |
| 新財帛 | 亥 | 武曲＋巨門 | 事業的財：行動＋口才 |

→ 事業眉型結論：眉峰明確（開創）＋ 眉型沉穩（智慧）——與原設計一致，但更聚焦眉峰

### 完整 144 宮對照的推導方法

```

   原財帛卯 + 8 = 亥 → 新事業 = 亥
```

## 六、方法論取捨標註（重要）

### 本系統的轉宮原則（KenEyeCue 方法論取捨）

1. **轉宮層數**：最多 1 層（立太極一次）
   ——理由：多次轉宮易流於事後套用（本系統的方法論取捨，非公認權威論述，對外說明請標註）
2. **轉宮用途**：只用於「深化」原 5 維度，不取代原分析
3. **轉宮時機**：客戶特別在意某領域時才用
4. **空宮處理**：新宮位為空宮時，借對宮（與原命盤規則一致）

### 對外話術標註範例

```
「這是我們 KenEyeCue 的專業判斷——
   這個分析我們最多做一層，避免過度解讀。
   這是我們的判斷，不是所有流派都這樣。」
```

（註：對外話術依客戶端鐵律，不使用「轉宮」等命理術語，已翻成白話。）
