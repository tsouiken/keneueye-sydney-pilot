## 二、這類漏斗的公版打法（⚪ 品類慣例推測）

「命理 + MZ 人設 + IG 廣告」這類產品，市場上常見的漏斗結構：

1. 人設化角色（不是老派算命仙，是「網紅巫堂」形象，講話像朋友、用迷因梗）
2. 免費小測驗開場（生日／選擇題），收集資料同時降低進入門檻
3. 半客製化結果 + 資訊缺口鉤子（免費段先給一擊「被說中」的感覺，完整版才要付費）
4. 輕量付費解鎖 + 訂閱升級（低價 PDF／報告 → 誘導月訂閱或加官方帳號做二次行銷）
5. 結果可截圖分享（IG 限動），作為最低成本的擴散機制

這套結構本身**跟命理內容無關**，是任何「測驗導流 + 內容解鎖」產品都在用的成長機制。這點很重要——代表我們可以借用機制，同時完全不去碰它的人設與話術。

## 四、可運用在 KenEyeCue 的具體創意結合

### 1. 免費結果加厚（優先度最高，呼應風險文件建議#1）
把 `quiz/quiz-logic.js` 的 `RESULTS`（目前每個維度只有 `line` + `desc` + `note` 三句）擴寫成有結構的短文：
別人看到什麼 → 為什麼會這樣讀 → 這在哪些場合最吃虧 → 你其實是什麼樣的人。
目標：讓使用者在按下 NT$499 之前，先經歷一次「這也太準了吧」——但這一擊來自**具體、可驗證的觀察**（眉眼結構＋場合），不是模糊的命理話術，符合品牌「可觀察、可驗證、可行動」的定位。

### 2. 結果分享卡（呼應風險文件建議#2，機制借用自這支廣告的品類慣例）
在 `quiz/index.html` 結果頁加一張 IG Story 尺寸（1080×1920）的視覺卡：維度名稱 ＋ 一句 hook ＋ KenEyeCue 標誌。這是這類廣告漏斗共同驗證有效的低成本擴散機制，值得直接搬過來——**借的是機制，不是巫堂視覺語言**，卡片風格延續現有「深炭黑／象牙白／暖金」品牌色。

### 3. 雪梨在地化的廣告投放架構（借用 UTM 命名慣例）
比照這支廣告 `ch / ct / country / utm_*` 的參數設計，幫雪梨試點建立自己的一套追蹤命名（例如 `ch=meta&ct=syd01&country=au&utm_source=ig&utm_medium=paid`），把 `quiz/index.html` 當作 IG 廣告的導流頁做小預算測試（如 AUD$50–100），驗證雪梨華人社群對測驗漏斗的 CTR 與轉換率。這件事不需要等任何產品改動，是現有頁面就能立刻測試的一步。

### 4. 角色人設化，但走「觀察員」不走「巫堂」
MZ무당的人設玩法（輕鬆、迷因化口吻、有記憶點）本身值得借——但角色定位要維持「第一印象觀察員」而非「算命師／薩滿」。可以在文案語氣上更活潑、更有記憶點（不必永遠一本正經），但核心立場「不算命、不保證結果」不能鬆動。這是差異化，不是保守。

### 5. 免費 → 輕付費 → 真人服務的漏斗延伸
這類 App 常見的下一步是「訂閱升級」，但 KenEyeCue 是真人服務，有它們沒有的優勢：`success.html` 付款成功頁後，可以更明確地銜接到既有的 `预约与服务登记表_v1.0.md` 或雪梨工作坊（`index.html`），把一次性 NT$499 的線上互動，轉成到店／到工作坊的實體轉換。App 只能賣訂閱續命，我們可以直接賣「見到本人」——這是它們永遠學不去的差異化。

### 6. 分眾在地化落地頁（比照 `-tw` 後綴模式）
如果未來要投放不只雪梨一個城市（墨爾本、布里斯本等），可以比照這支廣告用路徑後綴分市場的做法，做 `/quiz-syd`、`/quiz-mel` 這類輕量在地化版本（差異只在集合時間、地點、少量措辭），方便廣告素材與落地頁一一對應，不必整套重做。
